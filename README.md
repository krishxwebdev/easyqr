# EasyQR

A fast, private link-to-QR web app. QR codes are generated entirely in the browser.

## Run locally

On Windows, double-click `start-easyqr.bat`. It starts the required local server and opens the app automatically.

Or run it manually:

```bash
npm install
npm run dev
```

Do not open the source `index.html` directly—the app must be served by Vite. Build for production with `npm run build`.
